POW3R Pie Tools — Add-on

Installation
- Copy `pow3r_pie_tools_addon.py` into Blender's addons folder or install via Blender > Edit > Preferences > Add-ons > Install...

Usage:
- Enable the add-on in Preferences > Add-ons.
- Press Ctrl+W to open the pie menu in the 3D View (Window keymap). The pie contains:

Features:
- Duplicate To Selected
- Remove Particles
- Apply Shape Keys
- Clear Split Normals
- Remove Empty Booleans
- View Active Object
- Shapespark Validate Materials

Notes:
In the future, each of the operator above will be implemented in its own separate source file for modularity and linked to a main source file.
